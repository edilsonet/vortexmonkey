# shell

Chrome compartilhado do VORTEX (`@vortex/shell`): `VortexShell` (barra superior
com a Central de Comunicacao, contexto do vinculo, tema e rodape com a prova
regulatoria) e `LoginPage`.

Consumido pelo host (`apps/shell-web`) e pelos MFEs (`apps/mro-web`), de modo
que o quadro visual nao se duplica entre subdominios.
