5.5     Procedimentos para uso do SDRMe para documentos eletrônicos

 5.5.1   Para uso do SDRMe para documentos eletrônicos, o requerente deve incluir procedimentos
         de controle de revisão de documentos. Esses procedimentos devem incluir o cumprimento
         de revisões pelo pessoal ao qual os documentos são emitidos.

 5.5.2   Usuários de documentos eletrônicos que optarem por imprimir material (informações de
         dados, instruções, procedimentos, etc.) do documento eletrônico devem possuir
         procedimento para assegurar que as informações impressas utilizadas estão atualizadas e que
         o material desatualizado seja descartado.

 5.5.3   Em caso de uso para documentos eletrônicos, um SDRMe deve possuir um método de
         arquivamento de dados técnicos e procedimentais revogados por revisão. Um detentor de
         certificado deve arquivar versões anteriores de documentos para prover necessidades futuras
         de duplicação, regeneração, ou instruções de reconstrução.
