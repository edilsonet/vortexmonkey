11.4.       Para o Brasil como país de sobrevoo, se nenhum dos critérios para emissão de uma
            autorização especial for relevante, uma autorização especial poderá ser outorgada desde
            que identificado um nível equivalente de segurança operacional para o transporte aéreo.
